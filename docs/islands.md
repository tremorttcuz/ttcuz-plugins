# Свои островки на Java — полное руководство

Островок — нижняя панель TikTok с кнопками «Главная», «Друзья», «+», «Входящие» и «Профиль». В ttcuz её можно заменить своей, написанной на **Java**. Островок:

- сам рисует всю панель: стекло, выделение, иконки, подписи, кнопку «+», любые анимации и шейдеры AGSL;
- сам решает, где стоит каждая кнопка и куда попадает нажатие;
- первым получает касания панели.

Островок — **не плагин**. Это один Java-файл с классом, который наследует `cat.ttcuz.island.Island`. Мод компилирует его прямо на телефоне теми же инструментами, что и плагины (ECJ и D8), и рисует им панель. Островку доступна только панель: никакого API плагинов, сети, файлов или аккаунта.

> Нужен ttcuz 0.8.0 или новее. Шейдеры AGSL работают на Android 13+.

## 1. Где включить

**Настройки ttcuz → Оформление → Свои островки** (строка видна, когда островок включён).

| Пункт | Что делает |
|---|---|
| **Островок мода** | Обычный островок ttcuz |
| ***Пример*** (Мой островок, Неон, Док, Три кнопки, Аврора) | Встроены в мод уже скомпилированными и включаются мгновенно. **Сделать свой на его основе** открывает его исходник в редакторе |
| ***Свой островок*** | **Включить / Изменить / Поделиться / Удалить** |
| **Написать новый** | Редактор с шаблоном (пример «Мой островок») |
| **Вставить из буфера** | Собрать скопированный Java-код |
| **Открыть файл .java** | Собрать файл с телефона |

«Собрать и включить» компилирует островок (шаги видны в окне сборки) и сразу включает его.

## 2. Первый островок

```java
// @name Мой первый
// @author @me
package my.islands;

import cat.ttcuz.island.Styled;

public class First extends Styled {
    public First() {
        radius = 8;              // почти прямые углы
        indicator = LINE;        // полоска под выбранной кнопкой
        createShape = CIRCLE;    // круглая «+»
    }
}
```

- Строки `// @name` и `// @author` в начале файла — название и автор в меню.
- Пакет — любой свой (`my.islands`), кроме `cat.ttcuz.*`: он занят модом.
- В файле должен быть один `public class`. Он наследует `Island` или `Styled` и имеет конструктор без параметров.

## 3. Два способа: Styled и Island

| | `Styled` | `Island` |
|---|---|---|
| Что это | Готовый островок MD3, который меняется полями | Пустой лист: рисуете всё сами |
| Когда | Поменять вид, цвета, форму, кнопки, анимацию, добавить шейдеры | Совсем свой дизайн и своё поведение |
| Можно смешать | Да: наследуйтесь от `Styled` и переопределите `draw()` — вызовите `super.draw()` и рисуйте поверх или вместо | — |

## 4. Styled — все настройки

Все поля публичные, задаются в конструкторе. Размеры в **dp**, положения внутри панели — **доли** от 0 до 1.

### Цвета: `Ink`

| Запись | Что это |
|---|---|
| `Ink.of(0xFF1C1F2A)` | Обычный цвет ARGB |
| `Ink.ACCENT` | Акцент из настроек |
| `Ink.ON_ACCENT` | Белый или почти чёрный — читается на акценте |
| `Ink.TEXT`, `Ink.MUTED`, `Ink.CARD` | Текст, приглушённый текст, фон темы |
| `Ink.ACCENT.opacity(.4f)` | Любой из них с прозрачностью |
| `null` | Не рисовать |

Цвета темы сами следуют за акцентом и тёмной или светлой темой.

### Панель

| Поле | По умолчанию | Что делает |
|---|---|---|
| `barHeight` | `0` (как у TikTok) | Высота панели |
| `side` | `12` | Отступ от краёв экрана |
| `lift` | `6` | Подъём над нижним краем (когда задан `barHeight`) |
| `radius` | `-1` (капсула) | Скругление углов |
| `backdrop` | `true` | Размытое видео под панелью (вид — как выбрано в «Оформлении»: матовое, жидкое стекло; у «пластика» его нет) |
| `fill` | `Ink.CARD.opacity(.72f)` | Заливка |
| `stroke`, `strokeWidth` | `null`, `1` | Обводка |
| `shadow`, `shadowRadius`, `shadowY` | `null`, `14`, `4` | Тень |
| `barShader` | `null` | AGSL-шейдер вместо `fill` |
| `effect` | `null` | AGSL-шейдер поверх всей панели (см. [7](#7-шейдеры-agsl)) |

### Кнопки

| Поле | По умолчанию | Что делает |
|---|---|---|
| `order` | `{"home","friends","create","inbox","profile"}` | Какие кнопки есть, слева направо. Нет в списке — нет на панели |
| `positions` | `null` (поровну) | Доля ширины для каждой кнопки из `order` |
| `buttonY` | `.5f` | Высота кнопок внутри панели |
| `iconSize` | `24` | Размер иконок |
| `iconColor`, `iconSelected` | `MUTED`, `ACCENT` | Цвета иконок |
| `filledSelected` | `true` | Выбранная иконка залитая |
| `selectedScale`, `pressScale` | `1`, `.88f` | Увеличение выбранной, сжатие под пальцем |
| `labels` | `NONE` | `NONE`, `BELOW` (под всеми), `SELECTED` (под выбранной), `BESIDE` (справа внутри выделения, как в MD3) |
| `labelSize`, `labelColor`, `labelSelected` | `11`, `MUTED`, `TEXT` | Подписи |

### Выделение

| Поле | По умолчанию | Что делает |
|---|---|---|
| `indicator` | `PILL` | `PILL`, `CIRCLE`, `LINE`, `DOT`, `NONE` |
| `indWidth`, `indHeight` | `56`, по форме | Размер |
| `indRadius` | половина высоты | Скругление |
| `indY` | по форме | Где по высоте панели |
| `indColor` | `ACCENT 28%` | Цвет |
| `stretch` | `.35f` | Насколько тянется в полёте |
| `indShader` | `null` | AGSL вместо цвета |

### Кнопка «+»

| Поле | По умолчанию | Что делает |
|---|---|---|
| `createShape` | `SUNNY` | `SUNNY`, `CIRCLE`, `SQUARE`, `SQUIRCLE`, `PILL`, `NONE` |
| `createSize`, `plusSize` | `44`, `24` | Размеры |
| `createColor`, `plusColor` | `ACCENT`, `ON_ACCENT` | Цвета |
| `spin` | `45` | Поворот после нажатия, в градусах |
| `createShader` | `null` | AGSL вместо цвета |

### Анимация

| Поле | По умолчанию | Что делает |
|---|---|---|
| `duration` | `320` | Длительность перелёта выделения, мс |
| `easing` | `SPRING` | `SPRING`, `SMOOTH`, `LINEAR`, `BOUNCE` |

## 5. Island — всё вручную

```java
public abstract class Island {
    public void layout(Bar bar) {}                              // где что стоит
    public abstract void draw(Canvas canvas, Bar bar);          // рисует всю панель
    public boolean onTouch(Bar bar, MotionEvent event) { ... }  // любое касание панели
    public boolean onTap(Bar bar, int tab) { ... }              // нажатие на кнопку
    public boolean onHold(Bar bar, int tab) { ... }             // долгое нажатие
    public void onRelease() {}                                  // островок выключили
}
```

- **`layout(bar)`** вызывается перед каждым кадром. Поставьте `bar.body` и `bar.radius` (форма панели), `bar.x[i]` и `bar.y[i]` (центр иконки кнопки `i`), `bar.hit[i]` (область нажатия). В полях уже лежит раскладка мода, так что менять можно только нужное.
- **`draw(canvas, bar)`** рисует всё. Мод не рисует ничего своего. Без выделения памяти и без работы с файлами: это кадр TikTok.
- **`onTouch`** получает каждое касание панели в её координатах. Вернули `true` — мод с этим касанием ничего не делает.
- **`onTap`**: вернули `false` — TikTok откроет вкладку; `true` — нажатие ваше.
- **`onHold`** — долгое нажатие.
- Для анимаций вызывайте `bar.animate(true)` в `layout()`, пока анимация идёт, и `bar.animate(false)`, когда закончилась.

Полный пример с нуля — [`Compact.java`](../islands/Compact.java).

## 6. Bar — что знает островок

Координаты — панели: (0, 0) — левый верхний угол, `width × height` в пикселях.

| Поле | Что в нём |
|---|---|
| `width`, `height`, `density` | Размер полосы в пикселях, пикселей на dp |
| `count`, `create` | Сколько кнопок (до 5), какая из них «+» (−1 — нет) |
| `role[i]` | Что открывает кнопка: `HOME`, `FRIENDS`, `CREATE`, `INBOX`, `PROFILE` |
| `selected`, `previous`, `progress` | Открытая вкладка, прошлая, переход 0 → 1 |
| `label[i]` | Название вкладки на языке телефона |
| `icon[i]`, `iconFilled[i]` | Иконки Material Symbols, контур и заливка, `Path` 24 × 24 |
| `plus` | Плюс, `Path` 24 × 24 |
| `pressed[i]` | Кнопка под пальцем |
| `picture[i]` | TikTok рисует здесь картинку (аватар друга) сам — не рисуйте иконку |
| `accent`, `text`, `muted`, `card`, `dark` | Цвета темы |
| `glass` | Стекло в настройках: 0 матовое, 1 жидкое, 2 пластик |
| `time` | Время кадра, мс |
| **out:** `body`, `radius`, `x[]`, `y[]`, `hit[]` | Ваша раскладка (см. выше) |

Помощники:

| Метод | Что делает |
|---|---|
| `dp(v)` | dp → пиксели |
| `drawSymbol(canvas, path, cx, cy, size, paint)` | Рисует иконку 24 × 24 по центру |
| `drawBackdrop(canvas, rect, radius)` | Размытое видео под панелью |
| `sunny(size)` | Форма «солнышко» MD3 |
| `shader(agsl)`, `uniform(shader, name, values…)` | Шейдер для `Paint.setShader` |
| `effect(agsl)` | Шейдер поверх всей панели |
| `open(tab)` | Открыть вкладку, как нажатием |
| `tick()` | Короткая вибрация |
| `Bar.mix(a, b, k)`, `Bar.fade(c, k)`, `Bar.on(c)` | Смешать цвета, сделать прозрачнее, цвет «на» цвете |
| `animate(on)` | Перерисовывать каждый кадр, пока on |

## 7. Шейдеры AGSL

Шейдер — программа для видеокарты на AGSL (язык шейдеров Android, похож на GLSL). Работает на Android 13+. На старых телефонах `shader()` возвращает `null`, и `Styled` рисует обычным цветом.

В `Styled` шейдер — строка в `barShader`, `indShader`, `createShader` или `effect`. В точку `p` (пиксели от левого верхнего угла фигуры) мод передаёт uniform, если шейдер их объявил:

| Объявление | Что приходит |
|---|---|
| `uniform float2 size;` | Размер фигуры |
| `uniform float time;` | Секунды. Если есть, панель перерисовывается каждый кадр |
| `uniform float progress;` | Перелёт выделения 0 → 1 |
| `uniform float selected;` | Номер выбранной кнопки в `order` |
| `uniform float pressed;` | 1, пока палец на панели |
| `uniform float dark;` | 1 в тёмной теме |
| `uniform half4 accent;` | Акцент |

`effect` получает нарисованную полосу как `uniform shader content;` и может её исказить: `content.eval(p)`.

В своём `Island` то же самое делается вручную:

```java
Object glow = bar.shader("uniform float2 size; half4 main(float2 p) { return half4(p.x / size.x, 0.4, 0.9, 1.0); }");
if (glow != null) { bar.uniform(glow, "size", w, h); paint.setShader((android.graphics.Shader) glow); }
```

Ошибка в шейдере выключает островок с текстом ошибки (см. [10](#10-защита-от-вылетов)).

## 8. Нажатия, вкладки, значки

- Нажатие попадает в ту кнопку, в чью область `hit` оно пришло. Мод передаёт его настоящей вкладке TikTok, поэтому всё открывается как обычно.
- Нажатие на панель мимо всех областей не делает ничего.
- Значки непрочитанного едут за `x[i]`, `y[i]`. Кнопку без места (`hit` пустой, `x` за экраном) значок не найдёт.
- Выключатели вкладок в «Оформлении» островка мода действуют и тут: скрытой вкладки нет в `count`.

## 9. Сборка на телефоне и ошибки

1. Первая сборка один раз скачивает `android.jar` с серверов Google (25 МБ), как у редактора плагинов.
2. Java 8: без `var`, `record` и текстовых блоков `"""`. Лямбды можно.
3. Ошибка компиляции показывается окном с номером строки; «Исправить» возвращает в редактор с вашим текстом, «Скопировать» копирует ошибку.
4. Островок хранится в данных мода: исходник, `classes.dex` и название. Повторная сборка «Изменить» заменяет старый.

## 10. Защита от вылетов

1. Исключение в `layout`, `draw`, `onTouch`, `onTap` или `onHold` выключает островок с сообщением, и возвращается островок мода.
2. Если TikTok всё же упал из-за островка, мод выключает островок прямо в момент падения. После перезапуска будет сообщение «Островок выключен: из-за него TikTok вылетел».
3. Если упала видеокарта (например, на шейдере), мод при следующем запуске видит, что TikTok упал во время работы островка, и выключает его (Android 11+).

Выключенный островок не удаляется: исправьте и включите снова.

## 12. Рецепты

**Свой цвет выделения поверх Styled:**

```java
@Override public void draw(Canvas canvas, Bar bar) {
    super.draw(canvas, bar);
    // свои пометки поверх
}
```

**Свой ответ на нажатие:** долгое нажатие на «Профиль» — вибрация и открытие «Входящих».

```java
@Override public boolean onHold(Bar bar, int tab) {
    if (bar.role[tab] != Bar.PROFILE) return false;
    for (int i = 0; i < bar.count; i++) if (bar.role[i] == Bar.INBOX) { bar.tick(); bar.open(i); }
    return true;
}
```

**Только две кнопки по краям:**

```java
order = new String[]{"home", "profile"};
positions = new float[]{.15f, .85f};
```

**Плоская панель во всю ширину без стекла:**

```java
backdrop = false; fill = Ink.CARD; radius = 0; side = 0; lift = 0;
```

## 13. Частые вопросы

**Можно ли сделать панель выше, чем у TikTok?** Нет: островок рисуется в нижней полосе, которую отвёл TikTok.

**Можно ли шестую кнопку?** Нет, вкладок TikTok пять. Но через `onTap` или `onHold` любая кнопка может делать своё.

**Батарея?** Без `time` в шейдерах и без `animate(true)` островок рисуется, только когда что-то меняется.

**Чем это отличается от плагина?** Островок видит только панель. Ему не нужны разрешения, и он не может навредить, поэтому его можно брать у кого угодно.
