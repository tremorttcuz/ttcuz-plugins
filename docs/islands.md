# Свои островки (.island) — полное руководство

Островок — это нижняя панель TikTok с кнопками «Главная», «Друзья», «+», «Входящие» и «Профиль». В ttcuz её можно полностью заменить своей. Можно поменять:

- форму и стекло панели;
- какие кнопки есть, в каком порядке и где именно они стоят;
- как выглядит выбранная кнопка и как выделение перелетает к другой;
- кнопку «+»;
- подписи;
- анимацию;
- любую часть, нарисовав её своим **шейдером AGSL**.

Островок — **не плагин**, а отдельный файл с расширением `.island`, внутри которого текст в формате JSON. Мод сам рисует панель по описанию из файла. Никакого кода, кроме шейдеров для видеокарты, в островке нет. Поэтому островок не может ничего, кроме внешнего вида панели: не видит аккаунт, не ходит в интернет, не трогает файлы. Его безопасно ставить от кого угодно.

> Нужен ttcuz **0.8.0** или новее. Шейдеры работают на **Android 13+**, остальное — на любом Android, который поддерживает мод.

## 1. Где включить и как поставить

**Настройки ttcuz → Оформление → Свои островки.** Строка видна, когда в «Оформлении» включён сам островок.

В меню:

| Пункт | Что делает |
|---|---|
| **Островок мода** | Обычный островок ttcuz. Галочка — если выбран он |
| *название островка* | Установленный островок. Нажатие открывает: **Включить**, **Изменить**, **Поделиться**, **Удалить** |
| **Примеры** | Пять готовых островков, они идут вместе с модом. Выбранный ставится и сразу включается |
| **Написать новый** | Редактор с шаблоном. «Сохранить и включить» проверяет файл, сохраняет и включает его |
| **Вставить из буфера** | Берёт скопированный текст островка (из чата, с сайта, из этого репозитория) |
| **Открыть файл .island** | Выбор файла на телефоне (до 64 КБ) |

Островки хранятся в данных мода (`files/ttcuz/islands/`). Имя файла получается из поля `name`. Островок с тем же названием заменяет старый, так удобно выпускать обновления.

**Поделиться** отправляет весь текст файла через любое приложение. Второй человек нажимает «Вставить из буфера» или сохраняет текст в файл `.island` и открывает его.

## 2. Первый островок за минуту

Самый короткий островок:

```json
{
  "island": 1,
  "name": "Мой островок"
}
```

- `"island": 1` — версия формата. Без неё файл не считается островком.
- `"name"` — название, оно видно в меню.

Всё остальное берётся по умолчанию, и получается аккуратная капсула в стиле Material 3.

Теперь поменяем что-нибудь заметное — квадратная панель, полоска вместо капсулы, круглый «+»:

```json
{
  "island": 1,
  "name": "Квадрат",
  "bar": { "radius": 8, "fill": "#E6101010" },
  "indicator": { "shape": "line", "width": 32 },
  "create": { "shape": "circle" }
}
```

Скопируйте, нажмите **Свои островки → Вставить из буфера**, и панель сразу поменяется.

## 3. Как устроен файл

```json
{
  "island": 1,
  "name": "Название",
  "author": "@ваш_ник",
  "version": "1.0",

  "bar":       { },
  "buttons":   { },
  "indicator": { },
  "create":    { },
  "motion":    { }
}
```

| Поле | Обязательно | Что это |
|---|---|---|
| `island` | да | Версия формата. Сейчас `1`. Файл для более новой версии мод не откроет и скажет об этом |
| `name` | да | Название, до 40 символов |
| `author` | нет | Автор, до 40 символов. Показывается рядом с названием |
| `version` | нет | Версия вашего островка, до 16 символов |
| `bar` | нет | Панель: размер, форма, стекло, заливка, обводка, тень, шейдеры |
| `buttons` | нет | Кнопки: какие, где, какого цвета и размера, подписи |
| `indicator` | нет | Выделение выбранной кнопки |
| `create` | нет | Кнопка «+» |
| `motion` | нет | Анимация перелёта выделения |

**Неизвестное поле — ошибка.** Если вы опечатались (`"radus"` вместо `"radius"`), мод не промолчит, а назовёт поле и перечислит допустимые. Если поле есть, но значение не подходит (число вне пределов, неизвестное слово), мод тоже скажет, что именно не так.

## 4. Единицы и координаты

- **Размеры** (`height`, `size`, `radius`, `width`…) — в **dp**, как в Android: одинаковые на разных экранах. 1 dp ≈ 1/160 дюйма.
- **Положения внутри панели** (`buttons.y`, `buttons.x`, `indicator.y`) — **доли** от 0 до 1:
  - `0` — левый или верхний край панели;
  - `0.5` — середина;
  - `1` — правый или нижний край.
- **Время** (`motion.duration`) — в миллисекундах.
- **Углы** (`create.spin`) — в градусах.

Панель рисуется внутри нижней полосы TikTok, где у него стоят вкладки. Полоса находится там же, где у TikTok, а панель внутри неё вы двигаете отступами `side` и `lift` и задаёте высоту `height`.

## 5. Цвета

Цвет можно записать так:

| Запись | Что значит |
|---|---|
| `#RGB` | Короткая запись: `#F80` = `#FF8800` |
| `#RRGGBB` | Обычный цвет, непрозрачный |
| `#AARRGGBB` | С прозрачностью: `AA` от `00` (прозрачный) до `FF` (непрозрачный). `#80000000` — полупрозрачный чёрный |
| `accent` | Цвет акцента из настроек ttcuz |
| `on accent` | Белый или почти чёрный — то, что читается поверх акцента |
| `text` | Цвет текста темы |
| `muted` | Приглушённый текст темы |
| `card` | Фон карточек темы |
| `… 40%` | Любой из цветов выше с прозрачностью: `accent 40%`, `#FFFFFF 15%`, `card 72%` |
| `none` | Не рисовать вообще |

Если писать `accent`, `text`, `muted`, `card` вместо конкретных цветов, островок сам подстроится под акцент и под тёмную или светлую тему, которые выбрал человек.

`text`, `muted` и `card` берутся из оттенка стекла, выбранного в настройках ttcuz («Авто», «Тёмный», «Светлый»).

## 6. `bar` — панель

```json
"bar": {
  "height": 60,
  "side": 12,
  "lift": 6,
  "radius": 30,
  "backdrop": true,
  "fill": "card 72%",
  "stroke": "text 8%",
  "strokeWidth": 1,
  "shadow": "#40000000",
  "shadowRadius": 14,
  "shadowY": 4,
  "shader": "…",
  "effect": "…"
}
```

| Поле | Тип | По умолчанию | Пределы | Что делает |
|---|---|---|---|---|
| `height` | число, dp | высота, которую даёт TikTok | 0–120 | Высота панели. `0` или нет поля — как у TikTok. Больше высоты полосы TikTok сделать нельзя |
| `side` | число, dp | 12 | 0–80 | Отступ от левого и правого края экрана. Большой отступ — узкая панель посередине |
| `lift` | число, dp | 6 | 0–60 | На сколько панель поднята над нижним краем полосы. Работает, когда задан `height` |
| `radius` | число, dp | капсула | 0–200 | Скругление углов. `0` — прямые углы. Всё, что больше половины высоты, даёт капсулу |
| `backdrop` | `true` / `false` | `true` | — | Рисовать под панелью размытое видео (см. ниже) |
| `fill` | цвет | `card 72%` | — | Заливка панели поверх размытого видео. `none` — без заливки |
| `stroke` | цвет | нет | — | Цвет обводки |
| `strokeWidth` | число, dp | 1 | 0–8 | Толщина обводки |
| `shadow` | цвет | нет | — | Цвет тени. Без этого поля тени нет |
| `shadowRadius` | число, dp | 14 | 0–40 | Насколько тень размыта |
| `shadowY` | число, dp | 4 | −20…20 | Сдвиг тени вниз (минус — вверх) |
| `shader` | AGSL | нет | — | Шейдер, которым заливается панель вместо `fill`. См. [раздел 11](#11-шейдеры-agsl) |
| `effect` | AGSL | нет | — | Шейдер поверх всей нарисованной панели. См. [раздел 12](#12-bareffect--шейдер-поверх-всей-панели) |

**Про `backdrop`.** Размытое видео под панелью берётся из настройки ttcuz **Оформление → стекло**:

- **матовое** — сильно размытое;
- **жидкое стекло** — почти прозрачное, с преломлением;
- **пластик** — без размытия: тогда `backdrop` ничего не рисует.

Если размытие выключено или телефон его не поддерживает, под панелью ничего нет, и видна только заливка `fill`. Поэтому `fill` с прозрачностью около 70% — хороший выбор: на любом телефоне панель читается.

## 7. `buttons` — кнопки

```json
"buttons": {
  "order": ["home", "friends", "create", "inbox", "profile"],
  "x": [0.1, 0.3, 0.5, 0.7, 0.9],
  "y": 0.5,
  "size": 24,
  "color": "muted",
  "selectedColor": "accent",
  "filledWhenSelected": true,
  "selectedScale": 1.0,
  "pressScale": 0.88,
  "labels": "none",
  "labelSize": 11,
  "labelColor": "muted",
  "selectedLabelColor": "text"
}
```

| Поле | Тип | По умолчанию | Пределы | Что делает |
|---|---|---|---|---|
| `order` | список | все пять по порядку | 1–5 кнопок | Какие кнопки есть и в каком порядке слева направо. Значения: `home` (Главная), `friends` (Друзья), `create` (+), `inbox` (Входящие), `profile` (Профиль). Кнопки, которой нет в списке, нет на панели. Повторять кнопку нельзя |
| `x` | список долей | поровну | 0–1 каждая | Где по горизонтали стоит каждая кнопка из `order`, по одному числу на кнопку и в том же порядке. Без поля кнопки делят ширину поровну |
| `y` | доля | 0.5 | 0–1 | Высота кнопок внутри панели |
| `size` | число, dp | 24 | 8–48 | Размер иконок |
| `color` | цвет | `muted` | — | Цвет невыбранных иконок |
| `selectedColor` | цвет | `accent` | — | Цвет выбранной иконки |
| `filledWhenSelected` | `true` / `false` | `true` | — | Выбранная иконка залитая, остальные контурные (как в Material 3). `false` — все контурные |
| `selectedScale` | число | 1 | 0.5–1.6 | Во сколько раз выбранная иконка крупнее. `1.15` — заметно, но аккуратно |
| `pressScale` | число | 0.88 | 0.5–1.2 | Во сколько раз кнопка сжимается, пока на ней палец. Больше `1` — кнопка, наоборот, растёт |
| `labels` | слово | `none` | — | Подписи, см. таблицу ниже |
| `labelSize` | число | 11 | 6–20 | Размер подписей |
| `labelColor` | цвет | `muted` | — | Цвет подписей невыбранных кнопок |
| `selectedLabelColor` | цвет | `text` | — | Цвет подписи выбранной кнопки |

**Подписи (`labels`):**

| Значение | Как выглядит |
|---|---|
| `none` | Только иконки |
| `below` | Подпись под каждой иконкой. Иконки сами чуть поднимаются, чтобы пара «иконка + подпись» стояла по центру `y` |
| `selected` | Подпись появляется только под выбранной кнопкой и плавно проявляется при переключении |
| `beside` | Как в Material 3 Expressive: выделение у выбранной кнопки становится шире, иконка уходит к его левому краю, а справа выезжает подпись. Лучше всего с `indicator.shape: "pill"` |

Подписи — те же слова, что пишет TikTok, на языке телефона.

**Значки, иконки, картинки.**

- Иконки — Google Material Symbols, те же, что в островке мода.
- Плюс у кнопки «+» — тоже Material Symbols.
- Когда TikTok показывает на вкладке «Друзья» аватар друга, островок не рисует там свою иконку: аватар рисует сам TikTok.

## 8. `indicator` — выделение

То, что стоит за выбранной кнопкой и перелетает при переключении.

```json
"indicator": {
  "shape": "pill",
  "width": 56,
  "height": 32,
  "radius": 16,
  "y": 0.5,
  "color": "accent 28%",
  "stretch": 0.35,
  "shader": "…"
}
```

| Поле | Тип | По умолчанию | Пределы | Что делает |
|---|---|---|---|---|
| `shape` | слово | `pill` | — | `pill` — капсула или скруглённый прямоугольник, `circle` — круг, `line` — полоска, `dot` — точка, `none` — выделения нет |
| `width` | число, dp | 56 | 2–200 | Ширина. Для `circle` и `dot` не нужна: их ширина равна высоте |
| `height` | число, dp | 32 (`line` — 3, `dot` — 5) | 1–120 | Высота |
| `radius` | число, dp | половина высоты | 0–100 | Скругление. Например, `pill` с `"radius": 6` — прямоугольник с мягкими углами |
| `y` | доля | 0.5 (`line` — 0.92, `dot` — 0.86) | 0–1 | Где по высоте панели стоит центр выделения |
| `color` | цвет | `accent 28%` | — | Цвет |
| `stretch` | число | 0.35 | 0–2 | Насколько выделение вытягивается, пока летит к другой кнопке. `0` — не тянется, `1` и больше — как капля |
| `shader` | AGSL | нет | — | Шейдер вместо цвета |

## 9. `create` — кнопка «+»

```json
"create": {
  "shape": "sunny",
  "size": 44,
  "color": "accent",
  "plusColor": "on accent",
  "plusSize": 24,
  "spin": 45,
  "shader": "…"
}
```

| Поле | Тип | По умолчанию | Пределы | Что делает |
|---|---|---|---|---|
| `shape` | слово | `sunny` | — | `sunny` — «солнышко» Material 3, `circle` — круг, `square` — квадрат со скруглением, `squircle` — сильно скруглённый квадрат, `pill` — горизонтальная капсула, `none` — без подложки, только плюс |
| `size` | число, dp | 44 | 16–72 | Размер кнопки |
| `color` | цвет | `accent` | — | Цвет кнопки |
| `plusColor` | цвет | `on accent` | — | Цвет плюса |
| `plusSize` | число, dp | 24 | 8–48 | Размер плюса |
| `spin` | число, градусы | 45 | −360…360 | На сколько кнопка поворачивается после каждого нажатия, плавно, с той же кривой, что `motion.easing`. `0` — не крутится. Плюс всегда остаётся ровным |
| `shader` | AGSL | нет | — | Шейдер вместо цвета (поворачивается вместе с кнопкой) |

Чтобы кнопки «+» не было совсем, уберите `create` из `buttons.order`.

## 10. `motion` — анимация

```json
"motion": { "duration": 320, "easing": "spring" }
```

| Поле | Тип | По умолчанию | Пределы | Что делает |
|---|---|---|---|---|
| `duration` | число, мс | 320 | 0–3000 | Сколько длится перелёт выделения. `0` — мгновенно |
| `easing` | слово | `spring` | — | Кривая движения, см. ниже |

| `easing` | Как движется |
|---|---|
| `spring` | Быстро, с лёгким перелётом и возвратом, как пружина |
| `smooth` | Быстрый старт, мягкая остановка |
| `linear` | Равномерно |
| `bounce` | С отскоками в конце |

С той же кривой меняются цвета иконок и подписей, увеличение выбранной кнопки (`selectedScale`) и поворот «+».

## 11. Шейдеры AGSL

Шейдер — маленькая программа для видеокарты, которая решает, какого цвета каждая точка фигуры. Островок поддерживает шейдеры для:

- панели (`bar.shader`);
- выделения (`indicator.shader`);
- кнопки «+» (`create.shader`);
- всей панели целиком (`bar.effect`, [раздел 12](#12-bareffect--шейдер-поверх-всей-панели)).

Шейдеры пишутся на **AGSL** — языке шейдеров Android, очень похожем на GLSL. Работают на **Android 13 и новее**. На старых телефонах шейдер не рисуется, вместо него берётся обычный цвет (`fill`, `color`). Поэтому указывайте цвет тоже — это запасной вариант.

### Как записать

Одной строкой:

```json
"shader": "uniform half4 accent; half4 main(float2 p) { return accent; }"
```

Или массивом строк — так читается намного лучше, мод склеит строки сам:

```json
"shader": [
  "uniform float2 size;",
  "uniform half4 accent;",
  "half4 main(float2 p) {",
  "  float k = p.x / size.x;",
  "  return half4(mix(half3(0.1), accent.rgb, half(k)), 1.0);",
  "}"
]
```

В шейдере обязательно должна быть функция `half4 main(float2 p)`. Она получает точку `p` и возвращает цвет `(r, g, b, a)` от 0 до 1.

### Координаты

`p` — точка **внутри фигуры** в пикселях, от её левого верхнего угла:

- у `bar.shader` — от угла панели;
- у `indicator.shader` — от угла выделения;
- у `create.shader` — от угла кнопки «+» (вместе с её поворотом).

Чтобы получить координаты от 0 до 1, разделите на размер: `float2 uv = p / size;`.

### Что передаёт мод (uniform)

Объявите в шейдере нужное, и мод будет присылать значение каждый кадр. Необъявленное он просто не трогает.

| Объявление | Что приходит |
|---|---|
| `uniform float2 size;` | Размер фигуры в пикселях (ширина, высота) |
| `uniform float time;` | Время в секундах; идёт по кругу каждый час |
| `uniform float progress;` | Перелёт выделения с кривой из `motion`: 0 в начале, 1 в конце |
| `uniform float selected;` | Номер выбранной кнопки в `buttons.order` (с нуля), или −1 |
| `uniform float pressed;` | 1, пока палец на панели, иначе 0 |
| `uniform float dark;` | 1, если панель тёмная, иначе 0 |
| `uniform half4 accent;` | Цвет акцента: `accent.rgb` — цвет, `accent.a` = 1 |

**Про `time` и батарею.** Если хотя бы один шейдер объявил `time`, панель перерисовывается каждый кадр — так получается анимация, но батарея тратится чуть больше. Без `time` панель рисуется только когда что-то меняется: переключение, нажатие, новая подпись.

### Проверка шейдера

Когда вы сохраняете островок, мод на Android 13+ сразу компилирует каждый шейдер. При ошибке он покажет текст ошибки компилятора и снова откроет редактор.

### Что есть в AGSL

- **Типы:** `float`, `float2/3/4`, `half`, `half2/3/4`, `int`, `bool`, `float2x2`…
- **Функции:** `sin`, `cos`, `atan`, `pow`, `exp`, `sqrt`, `abs`, `min`, `max`, `clamp`, `mix`, `step`, `smoothstep`, `fract`, `floor`, `mod`, `length`, `distance`, `dot`, `normalize`.
- **Можно** писать свои функции и циклы с постоянным числом шагов.
- **Нельзя** `texture()`: картинок у островка нет. Кроме `content` в `bar.effect` (см. ниже).

Подробно про язык: [документация Android по AGSL](https://developer.android.com/develop/ui/views/graphics/agsl).

## 12. `bar.effect` — шейдер поверх всей панели

`bar.shader` заливает только саму панель. А `bar.effect` — фильтр поверх **всего**, что уже нарисовано в нижней полосе: стекла, выделения, иконок, подписей, «+». Он может исказить картинку, перекрасить, добавить свечение или волны.

Нарисованная полоса приходит в шейдер как `uniform shader content;`. Без этого объявления мод не примет файл. Цвет точки берётся так: `content.eval(p)`.

```json
"effect": [
  "uniform shader content;",
  "uniform float2 size;",
  "uniform float time;",
  "half4 main(float2 p) {",
  "  float2 q = p + float2(0.0, sin(p.x * 0.05 + time * 2.0) * 1.5);",
  "  return content.eval(q);",
  "}"
]
```

- Здесь `p` — точка во **всей нижней полосе TikTok**, а `size` — размер этой полосы, а не панели.
- Работают те же uniform, что в [разделе 11](#что-передаёт-мод-uniform).
- Только Android 13+.

## 13. В каком порядке всё рисуется

Снизу вверх:

1. тень панели (`bar.shadow`);
2. размытое видео (`bar.backdrop`);
3. заливка панели — `bar.shader`, а если его нет или телефон старый, `bar.fill`;
4. обводка (`bar.stroke`);
5. выделение — `indicator.shader` или `indicator.color`;
6. иконки и подписи;
7. кнопка «+» — `create.shader` или `create.color`, сверху плюс;
8. `bar.effect` поверх всего этого.

## 14. Нажатия, вкладки и значки непрочитанного

- **Куда нажали, туда и попало.** Кнопки можно переставить, убрать, сдвинуть — нажатие попадает в ту кнопку, которую видно.
- **Область нажатия** у каждой кнопки — от середины до соседней слева до середины до соседней справа, на всю высоту полосы. Крайние кнопки достают до краёв панели.
- **Открывает вкладку сам TikTok.** Мод передаёт нажатие настоящей вкладке TikTok, поэтому всё открывается как обычно, «+» открывает камеру.
- **Значки непрочитанного** (число на «Входящих», точки) едут вместе с иконками туда, где они стоят у вас. У кнопок, которых нет в `order`, значков тоже нет.
- **Выключатели вкладок** в «Оформлении» островка мода (какие вкладки показывать) действуют и на ваш островок: скрытой там вкладки не будет, даже если она есть в `order`.

## 15. Защита от ошибок и вылетов

Островок не должен ломать TikTok, поэтому мод страхуется на каждом шаге:

1. **При сохранении** мод проверяет каждое поле и компилирует шейдеры (на Android 13+). Ошибочный файл не сохраняется: мод говорит, что не так, и возвращает в редактор с вашим текстом.
2. **Если островок сломался во время работы** (ошибка при раскладке, рисовании или нажатии), мод сразу выключает его, возвращает островок мода и пишет «Островок выключен из-за ошибки».
3. **Если TikTok всё-таки упал из-за островка**, мод выключает островок прямо в момент падения. После перезапуска будет обычный островок и сообщение «Островок выключен: из-за него TikTok вылетел — *название*».
4. **Если упала видеокарта** (например, шейдер, который конкретный телефон не потянул), такой вылет нельзя поймать в момент падения. Поэтому при следующем запуске мод смотрит, почему TikTok закрылся. Если это был такой вылет, а островок уже рисовался, островок выключается (Android 11+).

Выключенный островок не удаляется: его можно поправить в **Изменить** и включить снова.

## 17. Рецепты

### Плоская панель без стекла

```json
"bar": { "backdrop": false, "fill": "card", "radius": 0, "side": 0, "lift": 0 }
```

### Светлая панель на любой теме

```json
"bar": { "fill": "#F2F2F7", "stroke": "#14000000" },
"buttons": { "color": "#993C3C43", "selectedColor": "accent", "labelColor": "#993C3C43", "selectedLabelColor": "#1C1C1E" }
```

### Плавающая узкая капсула

```json
"bar": { "height": 52, "side": 60, "lift": 14, "shadow": "#59000000", "shadowRadius": 24, "shadowY": 8 }
```

### Только иконки, выбранная крупнее и ярче

```json
"buttons": { "labels": "none", "color": "#80FFFFFF", "selectedColor": "#FFFFFF", "selectedScale": 1.2 },
"indicator": { "shape": "none" }
```

### Кнопки в два края, «+» по центру

```json
"buttons": {
  "order": ["home", "friends", "create", "inbox", "profile"],
  "x": [0.08, 0.22, 0.5, 0.78, 0.92]
}
```

### Градиент по панели

```json
"bar": {
  "fill": "#E61A1A2E",
  "shader": [
    "uniform float2 size;",
    "uniform half4 accent;",
    "half4 main(float2 p) {",
    "  float k = p.x / size.x;",
    "  half3 a = half3(0.10, 0.10, 0.18);",
    "  half3 b = mix(a, accent.rgb, 0.35);",
    "  return half4(mix(a, b, half(k)), 0.92);",
    "}"
  ]
}
```

### Выделение, которое вспыхивает при переключении

```json
"indicator": {
  "shape": "pill",
  "shader": [
    "uniform float2 size;",
    "uniform float progress;",
    "uniform half4 accent;",
    "half4 main(float2 p) {",
    "  float flash = 1.0 - progress;",
    "  half3 c = mix(accent.rgb, half3(1.0), half(flash * 0.6));",
    "  return half4(c, 0.35 + 0.4 * flash);",
    "}"
  ]
}
```

### Мягкое свечение снизу панели (эффект)

```json
"bar": {
  "effect": [
    "uniform shader content;",
    "uniform float2 size;",
    "uniform half4 accent;",
    "half4 main(float2 p) {",
    "  half4 c = content.eval(p);",
    "  float glow = smoothstep(0.6, 1.0, p.y / size.y);",
    "  c.rgb += accent.rgb * half(0.25 * glow) * c.a;",
    "  return c;",
    "}"
  ]
}
```

### Пульсирующая «+»

```json
"create": {
  "shape": "circle",
  "shader": [
    "uniform float2 size;",
    "uniform float time;",
    "uniform half4 accent;",
    "half4 main(float2 p) {",
    "  float d = length(p / size - 0.5) * 2.0;",
    "  float pulse = 0.5 + 0.5 * sin(time * 4.0);",
    "  half3 c = mix(accent.rgb, half3(1.0), half(pulse * 0.25 * (1.0 - d)));",
    "  return half4(c, 1.0);",
    "}"
  ]
}
```

## 18. Сообщения об ошибках

| Сообщение | Что значит |
|---|---|
| `Нет поля "island": 1 — это не файл островка` | В файле нет `"island": 1` (или это вообще не островок) |
| `Островок для более новой версии мода (island N)` | Файл написан для формата новее, чем знает ваш ttcuz. Обновите мод |
| `Нужно поле "name"` | Нет названия |
| `JSON: …` | Ошибка в самом JSON: лишняя или пропущенная запятая, кавычка, скобка. В тексте сказано, на каком символе |
| `Неизвестное поле bar.radus (height / side / …)` | Опечатка в названии поля; в скобках — допустимые поля |
| `bar.radius: число от 0 до 200` | Число вне пределов |
| `…: цвет: #RRGGBB, #AARRGGBB, accent, …` | Цвет записан непонятно |
| `buttons.order: xyz — home / friends / create / inbox / profile` | Неизвестная кнопка в `order` |
| `buttons.order: home дважды` | Кнопка повторяется |
| `buttons.x: столько чисел, сколько кнопок в order (N)` | В `x` другое количество чисел |
| `…shader: в шейдере нет half4 main(float2 p)` | Нет главной функции шейдера |
| `…shader: <текст компилятора>` | Ошибка в коде шейдера (Android 13+) |
| `bar.effect: нужен uniform shader content;` | Эффект не объявил `content` |
| `Файл больше 64 КБ` | Слишком большой файл |
| `Островок выключен из-за ошибки` | Островок сломался во время работы и был выключен ([раздел 15](#15-защита-от-ошибок-и-вылетов)) |
| `Островок выключен: из-за него TikTok вылетел` | TikTok упал из-за островка; после перезапуска островок выключен |

## 19. Ограничения и частые вопросы

**Можно ли сделать панель выше, чем у TikTok?**
Нет. Островок рисуется внутри нижней полосы, которую отвёл TikTok. Ниже и уже можно, выше — нет.

**Можно ли добавить свою, шестую кнопку?**
Нет. Кнопки — это настоящие вкладки TikTok, их пять. Можно убрать, переставить и подвинуть.

**Можно ли поставить свои картинки вместо иконок?**
В формате 1 — нет: иконки берутся из Material Symbols. Зато цвет, размер, заливка, увеличение и подписи — ваши, а всё вокруг можно нарисовать шейдером.

**Островок на старом телефоне выглядит проще.**
До Android 13 шейдеров нет, вместо них рисуются цвета `fill` и `color`. Если размытие не поддерживается, под панелью нет видео.

**Батарея?**
Без `time` в шейдерах островок рисуется только при изменениях — как обычный. С `time` — каждый кадр, но это одна небольшая полоса внизу экрана.

**Где хранятся островки и что будет при обновлении мода?**
В данных мода. Обновление ttcuz их не трогает. При удалении TikTok с очисткой данных их нужно будет поставить снова.

**Можно ли выложить островок?**
Да. Это обычный текстовый файл — делитесь им где угодно: файлом `.island` или текстом.
