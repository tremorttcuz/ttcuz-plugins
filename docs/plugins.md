## 1. Что такое плагин

Плагин — это Java-класс, который наследует `cat.ttcuz.framework.plugin.TtcuzPlugin` и переопределяет только нужные ему методы-хуки. Мод вызывает хуки, когда в TikTok что-то происходит: открылся экран, пришла страница ленты, рисуется текст, сменился аккаунт. Через `ttcuz()` плагин получает всё, что даёт мод: настройки, окна, сеть, разрешения Android и другое.

Что плагин может:

- добавлять свои кнопки, панели и окна поверх любого экрана TikTok и менять его элементы;
- менять тексты, ники, цвета и регион, который видит TikTok;
- убирать или переставлять видео в ленте;
- ходить в интернет, показывать уведомления, сохранять файлы в «Загрузки»;
- с разрешения пользователя пользоваться камерой, микрофоном, местоположением, контактами и т. д.;
- иметь свою страницу настроек в моде.

Чего плагин не может:

- объявить свою Activity, Service или BroadcastReceiver: Android читает их из манифеста приложения при установке, а плагин появляется позже. Вместо этого — свои view поверх существующих экранов и окна мода;
- получить разрешение Android, которого нет в манифесте приложения (список — в [разделе 12](#12-разрешения-android));
- перехватывать произвольные методы TikTok: хуков ровно столько, сколько их в этом руководстве.

> **Безопасность.** Песочницы нет и быть не может: плагин работает внутри TikTok со всеми его правами. Разрешения из manifest.json — это обещание, которое проверяет мод (вызов без разрешения не сработает), и список, который пользователь видит под кнопкой с ключом. Ставьте только то, что прочитали сами или взяли из магазина: там каждый плагин проверен.

## 2. Как собрать: три способа

| Способ | Что нужно | Подробно |
|---|---|---|
| **Прямо в приложении** | только телефон | Настройки ttcuz → Плагины → **Редактор плагинов** |
| **Termux** на телефоне | Termux из F-Droid | [termux.md](termux.md) |
| **Компьютер** | JDK 17+ и Python 3 | [pc.md](pc.md) |

### В приложении

1. **Настройки ttcuz → Плагины → Редактор плагинов.**
2. Заполните «О плагине»: название, ID, версию, авторов (ники через запятую), главный класс, описание.
3. Отметьте **разрешения** — всё, чем пользуется плагин.
4. Пишите код во вкладках файлов (долгое нажатие на файл — удалить). Чтобы открыть готовый проект, нажмите **Открыть ZIP** (подойдёт и «Download ZIP» с GitHub).
5. Добавьте **картинку**: она обрежется в квадрат 128×128.
6. **Собрать и установить** — плагин компилируется на самом телефоне (ECJ и D8 уже внутри мода) и сразу ставится. Первая сборка один раз скачивает `android.jar` с серверов Google (25 МБ).
7. Ошибка компиляции открывается окном с номером строки и кнопкой «Скопировать».

Черновик сохраняется сам. **Экспорт ZIP** сохраняет исходники в файл.

### В Termux или на компьютере

```sh
ttcuz-plugin new my-plugin          # Termux: заготовка в «Загрузках»
ttcuz-plugin ~/storage/downloads/my-plugin
# или на компьютере:
python3 -m ttcuz.plugin my-plugin -o my-plugin.ctt
```

Готовый `.ctt` ставится в моде: **Настройки ttcuz → Плагины → Установить .ctt**.

## 3. Первый плагин за пять минут

**manifest.json**

```json
{
  "id": "com.me.hello",
  "name": "Hello",
  "name_ru": "Привет",
  "version": "1.0",
  "author": "me",
  "description_ru": "Здоровается при запуске.",
  "entry": "com.me.hello.Main",
  "api": 2,
  "tiktok": "47.2.41",
  "permissions": []
}
```

**java/com/me/hello/Main.java**

```java
package com.me.hello;

import cat.ttcuz.framework.plugin.PluginSettings;
import cat.ttcuz.framework.plugin.TtcuzPlugin;

public final class Main extends TtcuzPlugin {
    @Override
    public void onStart() {
        int starts = ttcuz().prefs().getInt("starts", 0) + 1;
        ttcuz().prefs().edit().putInt("starts", starts).apply();
        if (ttcuz().prefs().getBoolean("greet", true)) ttcuz().toast("Привет! Запуск №" + starts);
    }

    @Override
    public void onSettings(PluginSettings s) {
        s.toggle("greet", "Здороваться при запуске", true);
    }
}
```

Соберите любым способом из раздела 2. Плагин без разрешений: ему ничего не нужно, кроме своих настроек и сообщения на экране.

## 4. Устройство проекта и файла .ctt

**Проект:**

```
my-plugin/
├── manifest.json
├── icon.png                необязательно: квадрат, 128×128 достаточно
└── java/
    └── com/me/hello/
        └── Main.java       путь = пакет: com.me.hello → java/com/me/hello/
```

**Файл .ctt** — обычный ZIP:

```
my-plugin.ctt
├── manifest.json   обязательно
├── classes.dex     обязательно: весь код плагина, один dex
└── icon.png        необязательно
```

Правила и ограничения:

- В `classes.dex` не должно быть классов `cat.ttcuz.framework.plugin.*`: их даёт приложение, а вторая копия под тем же именем для Android — другой класс. Сборщик их исключает сам.
- Только один dex. Код уровня Java 17 разрешён; D8 переводит его под Android 7+ (min-api 24).
- Сторонние `.jar` не поддерживаются: переносите нужный код исходниками в `java/`.
- `manifest.json` до 64 КБ, `icon.png` — настоящий PNG.
- Для отправки на проверку пакет до 500 КБ, для публикации владельцем — до 1 МБ.
- Файл можно назвать как угодно: мод смотрит на содержимое, а не на расширение.

## 5. manifest.json — все поля

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | да | Имя плагина на диске и в настройках: латиница, цифры, `.`, `-`, `_`, начинается с буквы или цифры, до 128 символов. **По нему плагин обновляется** — не меняйте его между версиями. Удобно брать имя пакета: `com.me.hello`. |
| `entry` | да | Полное имя главного класса: `com.me.hello.Main`. Класс `public`, с конструктором без аргументов. |
| `name` | нет | Название в списке (по умолчанию `id`). |
| `name_ru`, `name_uk`, `name_en`… | нет | Название на языке телефона; если такого нет — `name`. |
| `version` | нет | Строка рядом с названием (по умолчанию `1.0`). Магазин сравнивает её с установленной и предлагает «Обновить». |
| `author` | нет | Авторы, ники через запятую: `nick1, nick2`. Показываются как `v1.0 • @nick1, @nick2`. |
| `description`, `description_ru`… | нет | Что делает плагин. В списке видны первые 4 строки, остальное — по нажатию. |
| `api` | нет | `2` — текущий API с разрешениями; `1` — старый, без списка (по умолчанию `1`). Мод отказывается ставить плагин с API новее своего, с понятной причиной. |
| `tiktok` | нет | Для какой версии TikTok. Если указано, должно быть `47.2.41`. |
| `permissions` | нет | Список разрешений: `["interface", "network", "android.permission.CAMERA"]`. Для API 2 нужно перечислить всё, чем пользуется плагин. До 32 элементов. |

## 6. Разрешения

Плагин API 2 перечисляет в `permissions` всё, что использует. Мод проверяет это в двух местах:

- **при запуске**: если плагин переопределяет хук, которому нужно разрешение, а разрешения в списке нет, плагин не запустится. В его карточке будет написано, каких разрешений не хватает;
- **при вызове**: метод `ttcuz()` без нужного разрешения бросает `SecurityException` с именем разрешения.

Пользователь видит список под кнопкой **с ключом** в карточке плагина, каждое разрешение — с иконкой и пояснением. Чувствительные (интернет, аккаунт, внутренности TikTok, разрешения Android) выделены цветом предупреждения. В магазине список виден в строке «Может: …».

| Разрешение | Что открывает | Хуки | Методы `ttcuz()` |
|---|---|---|---|
| `interface` | Свои кнопки и окна поверх экранов TikTok, изменение элементов | `onView`, `onScreen` | `overlay`, `find`, `views` |
| `text` | Тексты и ники | `onText`, `onNickname` | — |
| `feed` | Лента | `onFeed` | — |
| `colours` | Цвета приложения | `onColour` | — |
| `region` | Регион, который видит TikTok | `onRegion` | — |
| `events` | События мода и других плагинов | `onEvent` | — |
| `account` | id вошедшего аккаунта | `onAccountChanged` | `accountId` |
| `tiktok` | Скрытые методы и поля TikTok | — | `hostLoader`, `type`, `method`, `field` |
| `network` | Интернет | — | `http` |
| `notifications` | Свои уведомления | — | `notify` |
| `clipboard` | Буфер обмена | — | `copy`, `paste` |
| `storage` | Файлы в «Загрузки» | — | `saveDownload` |
| `android.permission.…` | Разрешение Android (раздел 12) | `onPermission` | `request`, `vibrate` (для `VIBRATE`) |

Без разрешений доступно: `prefs`, `accountPrefs`, `data`, `bundle`, `app`, `screen`, `accent`, `log`, `toast`, `ui`, `later`, `away`, `emit`, `dp`, `palette`, `animateIn`, `animateOut`, `dialog`, `menu`, `open`, `share`, `has`, `api`, `permissions`, `can` и все хуки, не перечисленные в таблице.

**Плагины API 1** работают без списка, как раньше: им по-прежнему доступны `accountId` и рефлексия к TikTok. Под ключом для них показывается список, собранный по хукам, которые они переопределяют. Новые возможности API 2 (`overlay`, `http`, `notify`…) требуют разрешения у всех плагинов.

## 7. Жизненный цикл плагина

```
установка ─▶ проверка пакета ─▶ загрузка класса ─▶ проверка разрешений
        ─▶ attach(PluginContext) ─▶ onLoad() ─▶ onStart() ─▶ onAccountChanged(uid) ─▶ onActivityResumed(текущий экран)
        ─▶ … хуки, пока плагин включён …
выключение / удаление / обновление ─▶ onStop() ─▶ ttcuz() закрыт: отложенные задачи отменены, его overlay убраны
```

- **Установка** проверяет пакет в отдельной папке и только потом подменяет старую версию. Если новая версия не запустилась, возвращается старая.
- **Обновление** — установка пакета с тем же `id`. Настройки (`prefs`, `accountPrefs`) и папка `data()` сохраняются.
- **onLoad()** вызывается один раз после загрузки, на фоновом потоке. Здесь можно подготовить данные; исключение отсюда — причина, по которой плагин не включится (она будет видна в карточке).
- **onStart() / onStop()** — плагин включён или выключен (переключатель, удаление, обновление). Вызываются на главном потоке.
- **Ошибка в любом хуке** перехватывается: TikTok не падает. Плагин помечается сломанным, останавливается, а текст ошибки показывается в его карточке и пишется в журнал мода. Чтобы запустить снова, выключите и включите его.
- **Безопасный режим** (Настройки ttcuz → Плагины → «Безопасный режим») — при старте TikTok не запускается ни один плагин. Нужен, если какой-то плагин мешает приложению открыться.

## 8. Хуки — полный список

Переопределяйте только нужные. Пустые хуки ничего не стоят: мод вызывает только переопределённые.

### Запуск и остановка

| Хук | Когда | Поток |
|---|---|---|
| `void onLoad() throws Exception` | Один раз после загрузки класса | фон |
| `void onStart()` | Плагин включён | главный |
| `void onStop()` | Плагин выключен, удалён или обновляется | главный |

### Экраны

| Хук | Когда | Поток | Разрешение |
|---|---|---|---|
| `onActivityCreated(Activity)` | Экран создан | главный | — |
| `onActivityResumed(Activity)` | Экран вышел на передний план. **Вызывается на каждом экране — должен быть быстрым** | главный | — |
| `onActivityPaused(Activity)` | Экран ушёл с переднего плана | главный | — |
| `onActivityDestroyed(Activity)` | Экран закрыт. Отпустите все ссылки на него | главный | — |
| `onScreen(Activity, ViewGroup content)` | Экран вышел на передний план **и уже разложен**: его элементы на своих местах. `content` — `android.R.id.content`. Удобнее всего для поиска и изменения элементов | главный | `interface` |

Главный экран TikTok — `com.ss.android.ugc.aweme.main.MainActivity`: лента, «Друзья», «Входящие» и профиль — фрагменты внутри него. Остальные имена классов TikTok запутаны и меняются от версии к версии.

### Содержимое

| Хук | Что делает | Разрешение |
|---|---|---|
| `List onFeed(List posts)` | Страница ленты до отрисовки. Верните тот же список или новый, без лишних постов. Элементы — объекты TikTok `Aweme` (читайте через рефлексию, раздел 15) | `feed` |
| `CharSequence onText(TextView view, CharSequence text)` | Текст перед выводом во view. Верните `text`, чтобы не менять | `text` |
| `String onNickname(String uid, String name)` | Ник перед выводом. Значки мода добавляются после этого хука | `text` |
| `int onColour(int colour)` | Каждый перекрашиваемый цвет. **Горячий путь**: здесь ничего не создавайте, не ищите и не пишите в журнал | `colours` |
| `void onView(View view)` | Каждый view, который мод перекрашивает. Часто — должен быть очень быстрым | `interface` |
| `String onRegion(String key, String value)` | Ответ TikTok о стране и операторе. `key`: `sim_country`, `network_country`, `sim_operator`, `network_operator`, `sim_operator_name`, `network_operator_name`; `value` — что мод собирался ответить | `region` |

### Аккаунт, настройки, события

| Хук | Когда | Разрешение |
|---|---|---|
| `onAccountChanged(String uid)` | Сменился аккаунт (`null` — вышли). Перечитайте `accountPrefs()` | `account` |
| `onSettings(PluginSettings)` | Строится страница настроек плагина (раздел 10) | — |
| `boolean onOpenSettings(Activity)` | Пользователь открыл настройки плагина. Верните `true`, если показали своё окно вместо страницы | — |
| `onPreferenceChanged(String scope, String key)` | Изменилась настройка: `scope` = `"plugin"` для `prefs()` или `"plugin-account"` для `accountPrefs()` | — |
| `onEvent(String name, Object value)` | Событие от мода или другого плагина (`ttcuz().emit`) | `events` |
| `onPermission(String permission, boolean granted)` | Пользователь ответил на запрос разрешения Android | — |

## 9. PluginContext — что даёт мод

`ttcuz()` внутри плагина возвращает его `PluginContext`. Всё ниже — его методы.

### Основное

| Метод | Что делает |
|---|---|
| `String id` | ID плагина из манифеста (поле) |
| `int api()` | Версия API из манифеста |
| `List<String> permissions()` | Разрешения из манифеста |
| `boolean can(String permission)` | Можно ли плагину это |
| `Context app()` | Контекст приложения. Безопасно хранить |
| `Activity screen()` | Экран на переднем плане или `null`. **Не храните** — берите заново |
| `String accountId()` | id вошедшего аккаунта или `null` (`account`) |
| `int accent()` | Цвет акцента, выбранный пользователем |
| `int[] palette()` | Цвета экранов мода сейчас: `{фон, карточка, текст}` |
| `int dp(float)` | dp в пикселях этого телефона |

### Хранение

| Метод | Что делает |
|---|---|
| `SharedPreferences prefs()` | Настройки плагина, общие для всех аккаунтов. Сюда же пишутся значения строк настроек (раздел 10) |
| `SharedPreferences accountPrefs()` | Настройки плагина для текущего аккаунта; без входа — отдельное хранилище «гостя» |
| `File data()` | Папка для своих файлов. Сохраняется при обновлении, удаляется вместе с плагином |
| `File bundle()` | Распакованный `.ctt` (только чтение): например, свои картинки рядом с `icon.png` |

### Сообщения и журнал

| Метод | Что делает |
|---|---|
| `void log(String)` | Строка в журнал мода с ID плагина (Настройки ttcuz → Журнал; в logcat с тегом `ttcuz`) |
| `void toast(String)` | Короткое сообщение на экране |
| `void dialog(title, message, ok, Runnable onOk, cancel)` | Окно в стиле мода. `cancel` = `null` — одна кнопка |
| `void menu(title, String[] items, Pick pick)` | Список на выбор; `pick.picked(index)` |

### Потоки

| Метод | Что делает |
|---|---|
| `void ui(Runnable)` | Выполнить на главном потоке |
| `void later(Runnable, long ms)` | На главном потоке через `ms` мс. Отменяется, когда плагин останавливают |
| `void away(Runnable)` | На собственном фоновом потоке плагина (один поток, задачи по очереди) |

Ошибка внутри `ui`, `later`, `away` обрабатывается так же, как ошибка в хуке.

### Интерфейс (`interface`)

| Метод | Что делает |
|---|---|
| `View overlay(Activity, View, int gravity)` | Поставить view поверх экрана в отдельный слой плагина. Касания вне view проходят в TikTok. Размеры и отступы берутся из `view.getLayoutParams()`, если они заданы |
| `View overlay(Activity, View)` | То же, в левом верхнем углу |
| `void removeOverlay(View)` | Убрать раньше времени (при остановке плагина всё убирается само) |
| `View find(Activity, String idName)` | Элемент TikTok по имени ресурса: `"title"` или `"com.zhiliaoapp.musically:id/title"` |
| `<T extends View> List<T> views(View root, Class<T>)` | Все элементы нужного типа под `root` |
| `void animateIn(View)` / `void animateOut(View, Runnable after)` | Анимации появления и ухода, как в моде. Учитывают настройку «Анимации» |

### Android и телефон

| Метод | Разрешение | Что делает |
|---|---|---|
| `boolean has(String androidPermission)` | — | Выдано ли разрешение Android |
| `void request(String androidPermission, Result result)` | то же `android.permission.…` | Спросить пользователя; ответ в `result.done(granted)` и `onPermission` |
| `String http(String url)` | `network` | GET по https, ответ до 2 МБ. Только из `away()` |
| `String http(method, url, body, contentType)` | `network` | Любой метод; `body` и `contentType` могут быть `null` |
| `void notify(String title, String text)` | `notifications` | Уведомление с именем плагина |
| `void copy(String)` / `String paste()` | `clipboard` | Буфер обмена |
| `Uri saveDownload(name, mime, byte[] bytes)` | `storage` | Файл в «Загрузки/ttcuz/<id>/» |
| `void vibrate(long ms)` | `android.permission.VIBRATE` | Короткая вибрация (до 2 с) |
| `void open(String url)` | — | Открыть ссылку в браузере или приложении |
| `void share(String text)` | — | Окно «Поделиться» |

### Внутренности TikTok (`tiktok`)

`hostLoader()`, `type(name)`, `method(type, name, params…)`, `field(type, name)` — раздел 15.

### Прочее

`emit(name, value)` — событие всем плагинам (раздел 16).

## 10. Настройки плагина

Мод строит страницу настроек плагина сам, по строкам, которые плагин описывает в `onSettings`. Кнопка с шестерёнкой в карточке плагина появляется, только если `onSettings` или `onOpenSettings` переопределены.

```java
@Override
public void onSettings(PluginSettings s) {
    s.text("Пояснение или заголовок");
    s.action("Сделать сейчас", () -> doIt());
    s.toggle("enabled", "Включено", true);                        // ключ, подпись, по умолчанию
    s.choice("mode", "Режим", new String[]{"А", "Б", "В"}, 0);     // индекс выбранного
    s.slider("size", "Размер", 10, 40, 20);                        // min, max, по умолчанию
    s.view(myView);                                                // любой свой View
}
```

| Строка | Значение в `prefs()` |
|---|---|
| `toggle(key, title, def)` | `getBoolean(key, def)` |
| `choice(key, title, options, def)` | `getInt(key, def)` — индекс |
| `slider(key, title, min, max, def)` | `getInt(key, def)` |
| `text`, `action`, `view` | не хранятся |

Ограничения: у `choice` хотя бы один вариант и `def` в пределах списка; у `slider` `min < max` и `def` между ними — иначе `IllegalArgumentException`.

Изменение любой строки вызывает `onPreferenceChanged("plugin", key)`.

**Свой экран настроек**: переопределите `onOpenSettings(Activity)`, покажите своё окно (например, `ttcuz().dialog(...)` или view через `overlay`) и верните `true`.

## 11. Интерфейс: свои кнопки и окна поверх TikTok

Нужно разрешение `interface`.

```java
@Override
public void onScreen(Activity activity, ViewGroup content) {
    if (!activity.getClass().getName().endsWith(".MainActivity")) return;
    if (button != null && button.isAttachedToWindow()) return;     // уже стоит
    TextView b = new TextView(activity);
    b.setText("★");
    b.setOnClickListener(v -> ttcuz().toast("Нажато"));
    FrameLayout.LayoutParams at = new FrameLayout.LayoutParams(ttcuz().dp(48), ttcuz().dp(48));
    at.setMargins(0, 0, ttcuz().dp(16), ttcuz().dp(140));
    b.setLayoutParams(at);
    button = ttcuz().overlay(activity, b, Gravity.BOTTOM | Gravity.END);
    ttcuz().animateIn(button);
}
```

Советы:

- **Слой плагина** лежит поверх всего экрана и не мешает касаниям: TikTok получает всё, что не попало в ваши view. У каждого плагина свой слой; при остановке плагина слой убирается.
- **Изменение элементов TikTok**: найдите их через `find` или `views` в `onScreen` и меняйте как обычные view (видимость, текст, цвет). TikTok может перезаписать изменения, когда перерисует экран: тогда повторите их в `onView` или в следующем `onScreen`.
- **Не храните Activity и view** дольше экрана: в `onActivityDestroyed` обнуляйте ссылки, иначе экран не освободится из памяти.
- **Цвета мода**: `ttcuz().accent()` и `ttcuz().palette()` — чтобы плагин выглядел как часть приложения.
- **Окна**: `ttcuz().dialog(...)` и `ttcuz().menu(...)` рисуются в стиле мода и подстраиваются под тему.

## 12. Разрешения Android

Плагин может попросить разрешение Android, только если оно:

1. есть в списке `permissions` манифеста плагина;
2. объявлено приложением. ttcuz объявляет для плагинов: `CAMERA`, `RECORD_AUDIO`, `ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION`, `READ_CONTACTS`, `READ_CALENDAR`, `READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO`, `READ_MEDIA_AUDIO`, `BLUETOOTH_CONNECT`, `VIBRATE`, а также `POST_NOTIFICATIONS` и всё, что объявил сам TikTok.

Само объявление ничего не выдаёт: Android спрашивает пользователя, только когда плагин вызывает `request`.

```java
if (!ttcuz().has("android.permission.CAMERA")) {
    ttcuz().request("android.permission.CAMERA", granted -> {
        if (granted) openCamera(); else ttcuz().toast("Без камеры не получится");
    });
}
```

Ответ приходит на главный поток — в `result` и в `onPermission`. Если приложение такого разрешения не объявляет, ответ сразу будет `false`, а причина появится в журнале.

## 13. Сеть, файлы, уведомления, буфер обмена

```java
ttcuz().away(() -> {
    try {
        String json = ttcuz().http("https://example.com/data.json");                         // network
        String answer = ttcuz().http("POST", "https://example.com/api", "{\"a\":1}", null);   // JSON по умолчанию
        ttcuz().notify("Готово", "Получено " + json.length() + " символов");                  // notifications
        ttcuz().saveDownload("data.json", "application/json", json.getBytes("UTF-8"));         // storage
    } catch (java.io.IOException e) {
        ttcuz().log("сеть: " + e.getMessage());
    }
});
```

- `http` — только `https://`, таймауты 15 с, ответ до 2 МБ. Код 4xx/5xx бросает `IOException` с текстом ответа. Вызов на главном потоке бросает `IllegalStateException`.
- `notify` на Android 13+ требует `POST_NOTIFICATIONS`: попросите его через `request` (см. пример `quote-of-the-day`).
- `saveDownload` возвращает `Uri` файла. Файлы для внутреннего пользования храните в `data()`.
- `copy` и `paste`: Android отдаёт содержимое буфера, только пока TikTok на экране.

## 14. Потоки и скорость

- **Главный поток** — все хуки экранов, `onStart`/`onStop`, `ui`, `later`. Не делайте здесь сеть, тяжёлые вычисления и работу с диском: TikTok начнёт тормозить. Вынесите это в `away`.
- **Горячие пути** — `onColour`, `onView`, `onText`: они вызываются сотни раз в секунду. Ничего не создавайте (никаких `new`), не ищите view, не пишите в журнал, не обращайтесь к `prefs()` в цикле — прочитайте настройку заранее в поле.
- **`onActivityResumed`** вызывается на каждом экране — только быстрые проверки.
- **Таймеры**: `later` отменяется при остановке плагина. Не запускайте частые повторы, пока TikTok в фоне: это расходует батарею. Проверяйте `ttcuz().screen() != null`.
- **Память**: не держите `Activity`, `View` и большие `Bitmap` в статических полях.

## 15. Доступ к классам TikTok

Нужно разрешение `tiktok` (плагинам API 1 доступно без него).

```java
Class<?> type = ttcuz().type("com.ss.android.ugc.aweme.feed.model.Aweme");
java.lang.reflect.Method getDesc = ttcuz().method("com.ss.android.ugc.aweme.feed.model.Aweme", "getDesc");
String caption = (String) getDesc.invoke(post);
```

`method` и `field` ищут и в родительских классах и сразу делают член доступным.

Осторожно:

- Большинство классов TikTok названы обфусцированно (`X.0TFu`) и **меняются в каждой версии**. Плагин, завязанный на такие имена, ломается при обновлении TikTok. Опирайтесь на стабильные имена (`Aweme`, `User`, `MainActivity`) и проверяйте `null`.
- Ошибка рефлексии внутри хука остановит плагин. Оборачивайте такие места в `try/catch`.
- Магазин проверяет рефлексию к аккаунту и сессии особенно строго.

## 18. Публикация в магазин и проверка

### Отправка

В редакторе нажмите **Отправить на проверку**: плагин собирается и отправляется вместе с исходниками и картинкой. Пакет должен быть до 500 КБ. Новая отправка того же плагина от того же автора заменяет ещё не проверенную.

### Автоматические проверки (ещё до модератора)

Код не принимается, если:

- **он запутан (обфусцирован)**:
  - большинство имён из одной-двух букв;
  - похожие друг на друга имена вроде `IlIl` и `O0O0`;
  - имена не латиницей;
  - `\u`-последовательности в коде;
  - строки длиной в тысячи символов или средняя строка длиннее 220 символов;
  - строки, расшифровываемые через XOR;
  - длинные закодированные строки (base64) и большие зашитые массивы данных;
- **он прячет код**: `DexClassLoader`, `InMemoryDexClassLoader`, `PathClassLoader`, `DexFile`, `defineClass`, `System.load`/`loadLibrary`, `Runtime.exec`, `ProcessBuilder`;
- **пакет не совпадает с исходниками**:
  - в `classes.dex` есть класс, которого нет в отправленных `.java`;
  - в пакете есть файлы, кроме `manifest.json`, `classes*.dex`, `icon.png`;
  - `manifest.json` пакета отличается от отправленного.

Редактор проверяет обфускацию ещё на телефоне и показывает причины до отправки.

### Gemini

После автоматических проверок код читает Gemini и пишет, что делает плагин и нет ли в нём опасного: кражи данных или токенов, скрытой отправки данных, вредных действий от имени пользователя. Если Gemini считает код запутанным, заявка отклоняется автоматически. Остальное — подсказка модератору.

### Модерация

Модератор видит исходники, разрешения, вердикт Gemini и одобряет или отклоняет. Одобренный плагин появляется в магазине с отметкой «Проверен» и ником отправителя. Обновление — новая отправка с тем же `id` и новой `version`.

### Хорошая заявка

- понятные имена классов, методов и переменных;
- в `permissions` только то, что действительно используется;
- описание, из которого ясно, что делает плагин;
- никаких скрытых сетевых запросов: адреса — строками в коде, а зачем — в описании.

## 19. Версии API и совместимость

| API | Что появилось |
|---|---|
| 1 | Хуки экранов, текста, ников, ленты, цвета, региона, событий, настроек; `prefs`, `accountPrefs`, `data`, `bundle`, рефлексия, `log`, `toast`, `ui`, `later`, `away`, `emit` |
| 2 | Разрешения в манифесте; `onScreen`, `onPermission`; `overlay`, `find`, `views`, `dialog`, `menu`, `palette`, `dp`, анимации; разрешения Android; `http`, `notify`, `copy`/`paste`, `saveDownload`, `open`, `share`, `vibrate` |

**Как перейти с API 1 на API 2**: поставьте `"api": 2` и перечислите в `permissions` всё, что использует плагин. Если что-то забыли, плагин не запустится и в карточке будет написано, какого разрешения не хватает.

**Плагины другого формата.** ttcuz ставит и запускает плагины совместимого формата (`.mtp`, `.mtb` — такой же ZIP с `manifest.json`, `classes.dex`, `icon.png`). Переименовывать не нужно: «Установить .ctt» принимает файл с любым расширением. Их хуки, настройки, окна, загрузки и журнал работают через ttcuz, названия и описания на языке телефона (`name_ru`…) поддерживаются. Такие плагины считаются плагинами API 1.

## 21. Ошибки и их решение

### При сборке

| Сообщение | Причина и решение |
|---|---|
| `javac not found: install JDK 17 or newer` | Не установлен JDK или он не в PATH. Termux: `pkg install openjdk-17` |
| `no manifest.json in …` | Неверная папка: укажите ту, где лежит `manifest.json` |
| `manifest.json has no id, entry …` | Не хватает обязательных полей |
| `api must be 1..2` / `tiktok '…'` | Плагин под другую версию API или TikTok |
| `permissions must be a list of names…` | `permissions` — не список или имя с недопустимыми символами |
| `manifest.json is not valid JSON` | Лишняя или пропущенная запятая, кавычки «ёлочки» вместо `"` |
| `id 'a b': Latin letters, digits…` | Недопустимые символы в `id` |
| `entry 'Main' is not a fully qualified class name` | Нужно полное имя: `com.me.hello.Main` |
| `the entry class … is not among the compiled classes` | Пакет в `.java` не совпадает с `entry` или путём папки |
| `no .java under …/java` | Исходники должны лежать в `java/` |
| `icon.png is not a PNG` | Файл переименован из jpg/webp: сохраните настоящим PNG |
| `javac failed` / окно «Сборка не удалась» | Ошибка в коде: строка и причина показаны в тексте |
| `OutOfMemoryError` (Termux) | Закройте другие приложения: D8 нужно несколько сотен МБ |

### При установке и запуске

| Сообщение | Причина и решение |
|---|---|
| «Плагину нужны разрешения в manifest.json: …» | Хук переопределён без разрешения — добавьте названное в `permissions` |
| `SecurityException: plugin … needs "…"` | Вызов `ttcuz()` без разрешения — добавьте его в `permissions` |
| `http() on the main thread: use away()` | Сеть только из `away()` |
| `only https:// addresses` | `http` не ходит по `http://` |
| «Нужен ttcuz Plugin API N» | Плагин требует API новее, чем у мода: обновите ttcuz |
| «Главный класс не является плагином» | Класс из `entry` не наследует `TtcuzPlugin` |
| «Класс плагина абстрактный» | `entry` указывает на абстрактный класс |
| «Безопасный режим: плагины не запускаются при старте» | Включён безопасный режим: выключите его в настройках плагинов |

### При отправке на проверку

| Сообщение | Что делать |
|---|---|
| «Код не прошёл проверку» + список причин | Уберите запутывание: понятные имена, без `\u` в коде, без шифрованных строк и зашитых данных |
| «Пакет не совпадает с исходниками» | Отправляйте из редактора: он собирает пакет из тех же исходников |
| `rate_limited` | Не больше 6 отправок в час с одного адреса |
| «Пакет больше 500 КБ» | Уменьшите картинку и код |

## 22. Частые вопросы

**Плагин работает после перезапуска TikTok?** Да: включённые плагины запускаются при каждом старте (кроме безопасного режима).

**Где хранить данные?** Мелкие — в `prefs()`/`accountPrefs()`, файлы — в `data()`. При обновлении плагина всё сохраняется, при удалении — удаляется.

**Можно ли использовать Kotlin?** Сборщик компилирует Java. Kotlin-код можно собрать в Java-совместимый dex отдельно, но магазин принимает только исходники на Java.

**Можно ли несколько файлов?** Да, до 32 `.java` в разных пакетах внутри `java/`.

**Как сделать плагин для одного аккаунта?** Храните настройки в `accountPrefs()` и проверяйте `accountId()` (разрешение `account`).

**Почему кнопка с шестерёнкой не появляется?** Нужно переопределить `onSettings` или `onOpenSettings`.

**Почему изменения в TikTok «откатываются»?** TikTok перерисовывает экран своими данными. Повторяйте изменение в `onScreen` или `onView`.

**Где полные сигнатуры?** `sdk/cat/ttcuz/framework/plugin/`: `TtcuzPlugin.java`, `PluginContext.java`, `PluginSettings.java`.
